# ha_europe

Term paper (Europäische Integration): multilevel logit analysis of gender and labour-market participation in the EU, using ESS Round 11.

## Data
The ESS data are not included (redistribution is not permitted).

1. Register (free) at https://www.europeansocialsurvey.org/data-portal and download ESS Round 11 as **CSV**.
2. Unzip it and copy the CSV file to `Analysis/Data/`.
3. Make sure the file name matches the name in Data_Cleaning.r

## Usage
Set the working directory at the top of each script, then run the scripts in `Analysis/`.
